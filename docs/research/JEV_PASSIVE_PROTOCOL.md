# 被动限价入场假设协议

2026-09-27，先冻结后搜索。目标仍为原始扣成本盈利与压力门槛，不下单。

前两轮显示市价执行成本难覆盖。本轮检验入场改为预先确定的被动限价是否改善净优势。**5m OHLC不能重现排队、部分成交及订单簿**，本轮仅为保守规则下的研究情景；即使通过独立标签也必须补组合、执行证据、未调参预留与前向验证，不可称实盘盈利。

复用成本感知引擎两类入场（EMA9/21密集突破、EMA20/60首次回踩），方向实体下限0、止损至少1.5/3ATR、决策ATR/close下限0/0.4%。订单价为信号收盘价向有利方向偏移0.25/0.75ATR；限价在下一根5m有效，过期取消。目标1/2R、最长30/60分钟（从订单生效计算）。共64组，不事后挑币或方向。

nextbar开盘使限价可立即成交时，保守按post-only取消；否则必须穿过限价1bp才假设全部成交，单纯触碰不算。入场根止损优先，不承认入场根止盈。后续止损优先于止盈、跳空止损取更差开盘。止盈和超时按taker退出计费滑点，禁止假设免费止盈。

研究费用：入场maker单边0.02%，退出taker0.05%和滑点0.05%；实际资金费，缺失8h位置不利补值0.01%。研究maker费率不是已核验账户费率。压力：所有费用与退出滑点翻倍，入场穿价要求提高到2bp，真实资金费不变。目标幅度在决策时须至少0.4%（沿用原空间底线）。

仅开发旧8币。训练07-31至08-27，A08-27至09-11，B09-11至09-26（UTC左闭右开）。训练至少80已成交独立标签，常规PF≥1.2、均值>0、压力PF≥1；最多前6进入A。按训练是否样本足够、常规PF、均值、样本数排序。A至少30笔、常规PF≥1.2和均值>0、压力至少30笔/PF≥1/均值≥0；A通过才冻结一个去B，B同门槛，两段合计至少100笔。

本轮是成交标签筛查，不是组合验收；即使通过也必须另外满足100U组合盈利、回撤≤20%、压力不亏和原仓位约束。开发筛查失败不打开新8币预留、不调用Jev。保留订单数、成交率、取消原因、全部参数结果。不得忽略未成交或降低样本要求。
