# 固定长历史1R目标与30分钟持仓修订协议

冻结日期：2026-09-27；1R训练失败归因后、任何新Jev评分与开发标签计算前冻结。

## 改动与动机

1R目标实验166笔成交中，32笔止盈、43笔初始止损、91笔持有到60分钟上限。到期组胜率31.87%、PF0.288、净收益均值-0.242%。下一轮保留1R目标，只将持仓上限从60分钟降至30分钟，检验更早退出是否减少未能及时兑现的订单损失。30分钟也可能过早退出仍在发展的盈利交易或造成样本不足；结果未测，不保证改善。

## 固定设置

- 数据：仍为原8币长历史、相同资金费和拼接版本；不读取预留价格。
- 信号、成本、成交规则、止损3 ATR、最小ATR比率0.004、无实体下限、0.25ATR被动限价以及`target_r=1.0`与 `JEV_LONG_HISTORY_TARGET_1R_PROTOCOL.md` 相同。
- 唯一策略参数变更：最大持仓从60分钟改为30分钟。最后完整5分钟K线收盘退出，其他OHLC路径和成本压力规则保持不变。
- Jev模型、endpoint、概率语义和六阈值[0.15,0.25,0.35,0.45,0.55,0.65]不变。训练只在原训练窗 `[2026-03-01, 2026-06-01)` 选择阈值。
- 开发A `[2026-06-01, 2026-07-15)` 与B `[2026-07-15, 2026-09-26)`仍为开发数据，不称独立样本外。

## 固定验收

训练常规和两种压力情景均至少80笔；常规净胜率≥50%、PF≥1.2、均值>0；两压力PF≥1、均值≥0。训练失败就停止，不计算开发标签。训练通过后阈值冻结；开发A/B各情景至少30笔且满足相同门槛，A+B常规至少100笔；A失败停止B。标签通过后才补组合回撤、资金约束、执行敏感性，最后才考虑未触碰的预留数据。不得下实盘订单。
