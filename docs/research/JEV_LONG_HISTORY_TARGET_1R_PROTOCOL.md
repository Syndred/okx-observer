# 固定长历史1R目标修订协议

冻结日期：2026-09-27；首轮训练失败归因后、任何新Jev评分与开发标签计算前冻结。

## 改动与动机

首轮2R长历史训练共166笔成交，116笔（69.9%）持有至60分钟到期，只有7笔触及2R；整体净胜率35.54%、PF0.509。下一轮只将止盈目标从2R改为1R，检验较近目标能否减少大量到期订单并提升扣费后结果。1R会降低每笔止盈的毛收益，这个假设可能失败；不能据此承诺盈利。

## 固定设置

- 数据：原8币BTC/ETH/SOL/XRP/DOGE/ADA/LINK/AVAX，长数据范围2026-02-26至09-26；不读取8币预留价格。行情、资金费和执行规则与 `JEV_LONG_HISTORY_PROTOCOL.md` 相同。
- 信号：双EMA9/21成本感知突破，`stop_atr=3`、`min_atr_pct=0.004`、`min_body_atr=0`；有利方向0.25ATR被动限价，持仓上限60分钟。
- 唯一策略参数变更：`target_r=1.0`。成交、跳空取消、穿价1bp、同根止损优先、maker0.0002、退出taker0.0005、滑点0.0005和真实/缺失资金费处理全部保持原协议。
- Jev endpoint、`jev-1.13.0`、请求字段与概率语义不变。只使用训练段择优原阈值0.15/0.25/0.35/0.45/0.55/0.65，不反转概率、不增删阈值、不修改门槛。
- 训练UTC `[2026-03-01, 2026-06-01)`；开发A `[2026-06-01, 2026-07-15)`；开发B `[2026-07-15, 2026-09-26)`。仍全部称开发数据，不能宣称独立样本外。

## 固定验收

训练常规及两种压力情景均至少80笔；常规净胜率≥50%、PF≥1.2、净收益均值>0；两压力PF≥1、均值≥0。训练失败则停止，不计算A/B标签。训练通过后阈值冻结；开发A/B各情景至少30笔且满足相同胜率/收益/压力要求，A+B常规至少100笔。A失败即停止B。所有开发标签通过后才补组合资金约束、最大回撤和执行敏感性，再考虑未触碰的8币预留；OHLC假设成交不等于真实队列或实盘收益。
