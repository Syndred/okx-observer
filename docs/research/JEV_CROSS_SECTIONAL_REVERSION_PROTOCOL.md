# 横截面短线反转研究协议

冻结日期：2026-09-27。此协议先于反向候选的标签计算提交。该假设来自同一训练段横截面动量失败后的下一轮研究：若短期相对强弱在30分钟内反转，则应做多过去一小时最弱者并做空最强者。训练段用于迭代筛选，任何结果都不能改写冻结门槛。

## 固定候选

- 固定开发币种 BTC、ETH、SOL、XRP、DOGE、ADA、LINK、AVAX 的5分钟K线。
- 每30分钟读取上一根已完整收盘的K线，计算每个币种过去12根（1小时）收盘收益，横截面收益差至少0.006（60bp）时才开仓。
- 做多收益最低者、做空收益最高者；收益相同按交易对字典序打破平局。每轮各一笔，按同一时点下一根5分钟开盘价入场。
- 止损依据决策K线收盘价和ATR14，设在相反方向1.5 ATR；目标为实际入场至固定止损距离的1R；止损优先，持仓最多30分钟，超时按最后完整5分钟K线收盘价退出。禁止同币种重叠仓位。
- 组合模拟使用初始资金100U、3倍杠杆、单笔常规风险0.75%、组合风险2%、最多3仓/同向最多2仓。

## 成本与分段

- 常规为单边手续费0.05%、单边滑点0.05%，叠加真实资金费；缺失UTC 00/08/16结算按单次0.01%不利计费。
- 成本压力把手续费、滑点和缺失资金费翻倍。严格压力在双倍成本上再把入场延迟一根5分钟K；信号与止损仍用决策时可知的数据，持仓上限从延迟后的实际入场时起算，若开盘越过止损则不成交。
- 训练为2026-03-01至2026-06-01（UTC左闭右开）；开发A为06-01至07-15；开发B为07-15至09-26。若训练失败不计开发A/B；A失败不计B。
- 预留币种SUI、NEAR、UNI、AAVE、LTC、BNB、DOT、ATOM，只有训练、开发标签和组合门槛全部通过后才可加载和评估，不得按其结果改参数。

## 固定晋级门槛

训练常规、成本压力和严格压力均至少80笔；常规净胜率至少50%、PF至少1.2、平均净收益大于0；压力PF均至少1、平均净收益不小于0。未达任一门槛即保留失败报告，不打开开发或预留绩效。

通过训练后参数冻结。开发A、B每段至少30笔；常规净胜率至少50%、PF至少1.2、平均净收益大于0，压力PF均至少1且平均净收益不小于0；两段常规合计至少100笔。开发组合每段至少30笔，常规期末权益大于100U、PF至少1.2、回撤不超过20%；压力期末权益至少100U且PF至少1，A+B常规至少100笔。

通过开发后才加载预留数据。预留至少100笔、净盈利、PF至少1.2、回撤不超过20%，双倍成本压力不亏；延迟入场结果单独报告。历史结果不保证未来或实盘收益，任何通过候选仍须前向模拟。
