# BTC方向过滤的横截面短线动量协议

冻结日期：2026-09-27。此前无方向过滤的横截面多空同步组合在训练期明显亏损。此候选只检验一个新假设：让 BTC 过去一小时方向决定风险偏好，并只交易同向的横截面极端币种，避免在基准趋势中逆势开仓。

## 固定信号与执行

- 固定开发币种 BTC、ETH、SOL、XRP、DOGE、ADA、LINK、AVAX，使用5分钟K线。
- 每30分钟以已收盘数据计算8币过去12根K线（1小时）收盘收益，要求横截面最高与最低收益差至少0.006（60bp）。
- BTC过去1小时收益>0时，只做多收益最高的币，且其自身过去1小时收益必须>0；BTC收益<0时，只做空收益最低的币，且其收益必须<0；BTC收益等于0、分化不足或方向条件不满足时不交易。同一时点最多一笔，收益并列按交易对字典序。
- 在用于计算信号的5分钟K收盘后，于下一根K开盘成交。止损为信号收盘价反向1.5 ATR14；目标1R按实际开仓与固定止损距离计算。止损优先，最长持仓30分钟，按最后完整5分钟K线收盘退出；每个币种不重叠持仓。
- 组合模拟沿用100U初始权益、3倍杠杆、每笔常规风险0.75%、总风险2%、最多3仓/同向最多2仓。

## 成本、分段与晋级

- 常规手续费和滑点各单边0.05%，叠加实际资金费；缺失UTC 00/08/16资金费按0.01%不利估算。成本压力将三种成本翻倍；严格压力在双倍成本上将入场延迟一根5分钟K线，使用原时点冻结的信号与止损。另以常规成本单列延迟表现。
- 训练2026-03-01至06-01 UTC（左闭右开）；开发A为06-01至07-15；B为07-15至09-26。训练失败不计算A/B；A失败不计算B。
- 训练常规、成本压力和严格压力各至少80笔；常规净胜率≥50%、PF≥1.2、平均净收益>0；压力PF均≥1、平均净收益均≥0。开发A/B各至少30笔、满足相同常规和压力门槛，A+B常规≥100笔。组合开发段各至少30笔，常规期末权益>100U、PF≥1.2、最大回撤≤20%，压力期末权益≥100U且PF≥1，A+B常规≥100笔。
- 只有训练、A/B标签与组合验收全通过，才读取预留币SUI、NEAR、UNI、AAVE、LTC、BNB、DOT、ATOM。预留至少100笔、净盈利、PF≥1.2、回撤≤20%，双倍成本不亏；另外报告延迟入场敏感性。

本轮不调横截面分化阈值、方向条件、止损/目标或持仓时限。不下实盘单，不将历史表现写成未来盈利保证；历史通过后仍需前向模拟。
