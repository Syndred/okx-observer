# 回踩后延续确认迭代协议

2026-09-27，在新网格搜索前固定。上一轮成本感知96组没有通过开发门槛。本轮假设来自失败成交：很多回踩交易在10分钟内止损，额外已收盘确认可能改善延续质量，但也可能追价且减少样本。

复用原EMA20/60首次回踩信号。仅在下一根连续5m K收盘超过信号K高点（多）/低点（空），且未触及原止损时确认；随后下一根开盘进入。不能提前获知该开盘价格。不再逐根无限等确认；所有币多空统一规则。

固定36组：止损至少1/2/3ATR，决策ATR/价格至少0/0.2%/0.4%，目标1/2R，持有30/60分钟。只放宽原结构止损。原信号冷却保持12根，包括确认失败者。

沿用成本感知轮同样的开发分段、训练前6选择和A/B门禁：训练至少80、PF≥1.2、均值>0、压力PF≥1；A/B各至少30笔、PF≥1.2、权益>100、回撤≤20%、压力PF≥1且权益≥100，两段合计至少100。A通过才冻结一个候选到B，不以B结果换候选。全部开发失败则不读取预留绩效、不调用Jev救亏损基线。

费用/滑点各单边0.05%、实际资金费，压力执行费用加倍。零执行成本反事实仅作诊断：手续费、滑点与缺失资金费补值为0，保留真实资金费；其重算路径可不同，不能将PF差值当作纯费用影响。前轮“零费用标签”同样指此口径，原协议文件为保存哈希不修改。

这是开发研究，旧A/B不能称独立样本外。任何通过版本仍需冻结后跨币种预留、延迟敏感性和前向验证，历史盈利不是收益承诺。
