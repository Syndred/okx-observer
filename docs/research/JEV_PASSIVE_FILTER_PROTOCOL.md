# Jev限价净盈利筛选协议

2026-09-27，在新模型预测和阈值选择前冻结。固定被动限价研究训练排名第一且样本足够的候选59，不重搜入场参数：EMA9/21突破、3ATR止损、ATR/close≥0.4%、0.25ATR限价偏移、2R目标、最长60分钟。已知开发A基线失败，因此本轮仍属于开发研究，不能把A称作新样本外。

新假设：Jev在发单前识别“按固定穿价规则成交后”的净盈利概率，可能筛去限价造成的不利成交。预测所有预先产生的订单，不根据未来是否成交预筛预测；未成交订单只进入未成交统计，不计净胜率。模型只接收决策时已收盘的标准化历史、固定限价/止损/退出成本规则，不提供日期、币名、未来开盘/成交结果/收益。概率是模型估计，不是实际胜率。

模型固定jev-1.13.0，复用真实API与按输入/模型/提供器代码哈希缓存。训练07-31至08-27，开发A08-27至09-11，B09-11至09-26（UTC左闭右开）。在训练从[0.15,0.25,0.35,0.45,0.55,0.65]中选择；每个阈值在常规1bp、只加倍成本1bp、成本加倍与2bp穿价三种情景重算。

训练每个情景至少80笔；常规PF≥1.2、净均值>0、净胜率≥50%；两种压力PF≥1、均值≥0。满足者按最差压力PF、常规PF排序冻结一个。无合格阈值则停在训练，不调用A预测、不回调候选、不消耗预留。

固定阈值后，A每种情景至少30笔且遵守同盈利/胜率/压力门槛；A失败不计算B。A通过再预测B，B同门槛且A+B常规总成交≥100。不因B失败改阈值。通过独立标签仍需原组合风控/回撤≤20%/双成本权益不亏，以及冻结后预留、执行敏感性和前向证据。当前研究没有真实队列/部分成交信息，不可直接认定实盘盈利。

这是对“训练存在净优势但A失效”的新筛选假设，允许在此前基线A失败后单独研究Jev；原费用、穿价、样本和最终验收不放宽。无伪造预测、无下单；保留全部6个阈值及失败原因。
