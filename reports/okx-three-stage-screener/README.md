# OKX 六均线四层机会筛选器

这套本地筛选器用于从大量 U 本位永续合约中寻找六均线缠绕、突破和第一次回踩机会，不自动下单。

## 当前四层

1. `entry_confirmed`：15m 突破后的第一次 MA20/EMA20 带回踩已收回，仅下一根 15m 开盘前有效。
2. `wait_first_pullback`：15m 已从成熟密集区突破，等待后续第一次回踩。
3. `mature_15m_coil`：15m 六线持续交织成熟，只观察，不是开仓信号。
4. `forming_15m_coil`：15m 正在收拢，尚未达到成熟条件，只观察。

## 扫描口径

- 不限制上市天数；`ageDays` 只保留作诊断。
- 形成中至少需要 127 根、成熟至少需要 135 根已收盘 15m K，避免在 MA120 尚不可计算时伪造密集。
- 4H 与日线是上下文，不再作为 15m 观察层的硬门槛；明确反向会附加 `opposite` 风险，并阻止最终回踩确认。
- 仍排除稳定币基准、非加密类别及 Bitget 没有 normal USDT 永续的合约；BTC/ETH 保留。
- 观察层只显示正分、连续且未失效的窗口，成熟与形成中合计最多 20 条。
- 只使用已收盘 K 线和 MA/EMA 20、60、120 加 ATR 标准化；不加入 ADX、成交量或订单簿信号。

## 运行

```bash
./scripts/open_three_stage_dashboard.sh
```

浏览地址：`http://127.0.0.1:8787/`。点击“扫描”通常需要约 3–4 分钟，同一次扫描会更新四层机会、24h 涨跌幅榜和连续涨跌/放量；扫描失败会保留上一份完整报告。

结果文件：

- `LATEST.md`：四层中文清单与完整参数。
- `latest.csv`：所有 live 合约、排除原因和诊断字段。
- `run-manifest.json`：本轮参数、计数、异常和口径边界。

Bitget 按钮只在官方合约交集确认可用时生成，且只用于人工查看。当前快照是形态筛选结果，不是回测盈利证明或实盘建议。

停止服务：

```bash
docker compose stop dashboard
```
