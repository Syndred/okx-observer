# OKX 合约持续缠绕筛选器

这个版本只负责从 OKX 全部 USDT 永续中找出值得打开图表复核的合约，不会自动下单。

## 当前规则

1. 合约至少上市 30 天。
2. 日线与 4H 必须同时处于同一方向的 EMA20/EMA60 趋势。
3. 当前价格必须位于 EMA20 的趋势侧，EMA60 最近三根 K 的斜率也必须同向。
4. 最近 16 根已收盘 15m K（4 小时）必须连续，其中至少 75% 的 K 线六线跨度不超过 2 ATR，且窗口末端至少连续 8 根仍保持密集。
5. 六根均线在窗口内至少相互穿越 4 次，并且这些交叉至少分布在 3 根 K 上；价格至少穿越六线中心 2 次。只有靠近但平行运行或一次集体换位，不算缠绕。
6. 六线中心在窗口内的总漂移不得超过 1 ATR，排除边走边贴合的伪震荡。
7. A 级还要求日线、4H 的六根均线完整顺排；B 级只要求基础 EMA20/60 趋势成立。

## 使用

在项目目录运行：

```bash
./scripts/scan_okx_now.sh
```

结果：

- `LATEST.md`：中文候选清单
- `latest.csv`：全部合约状态，可继续筛选或导入表格
- `run-manifest.json`：本次扫描时间、参数、数量和请求异常

行情会变化，每次准备交易前应重新运行。候选表示多周期趋势成立且 15m 已持续缠绕，处于“等待发散”阶段，不代表已经突破，更不代表应立即市价开仓；仍需人工确认发散方向、止损位置、资金费率和下单规格。
