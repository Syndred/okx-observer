# OKX 合约基础筛选器

这个版本只负责从 OKX 全部 USDT 永续中找出值得打开图表复核的合约，不会自动下单。

## 当前规则

1. 合约至少上市 30 天。
2. 日线与 4H 必须同时处于同一方向的 EMA20/EMA60 趋势。
3. 当前价格必须位于 EMA20 的趋势侧，EMA60 最近三根 K 的斜率也必须同向。
4. 15m 的 MA20/60/120 与 EMA20/60/120 六线跨度不超过 2 ATR。
5. A 级还要求日线、4H 的六根均线完整顺排；B 级只要求基础 EMA20/60 趋势成立。

## 使用

在项目目录运行：

```bash
./scripts/scan_okx_now.sh
```

结果：

- `LATEST.md`：中文候选清单
- `latest.csv`：全部合约状态，可继续筛选或导入表格
- `run-manifest.json`：本次扫描时间、参数、数量和请求异常

行情会变化，每次准备交易前应重新运行。候选只表示多周期趋势与均线密集条件成立，不代表应立即市价开仓；仍需人工确认当前 K 线、止损位置、资金费率和下单规格。
