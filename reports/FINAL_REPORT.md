# Crypto Trading System V1 本地回测报告

生成时间：2026-08-10（Asia/Shanghai）

## 结论先行

这套“六均线压缩 → 突破 → 第一次回踩”V1 在训练集与 2025 验证集上存在正收益，但在完全留出的 2026 数据上失效。因此，当前没有可建议实盘的“最优策略”，也没有证据支持它能把 100 USDT 稳定增长到 10,000 USDT。

- 研究阶段选出的最优信号参数：压缩阈值 1.5%、突破阈值 0.5%、3 根 1H K 线内第一次回踩、回踩容差 0.5%、固定 5R 止盈。
- 风险矩阵中相对最均衡：3x 杠杆、每笔风险 1%。
- 2026 留出结果：100U → 60.22U，PF 0.823，最大回撤 52.79%，连续亏损 35 笔。
- 2021-01 至 2026-08 连续结果：100U → 325.94U，历史最高 752.92U，PF 1.041，最大回撤 57.59%；没有触及 1,000U 或 10,000U。
- 10x/5% 风险组合历史最大回撤 99.54%，最低余额 11.75U，属于近乎爆仓，不可用。

所以 V1 的研究结论是“未通过跨年度稳健性验证”，而不是“已经找到可实盘策略”。

## 策略实现

### 多空双向

- 做多：六均线压缩区形成 → 收盘价向上突破区间上沿 → 突破后第一次回踩触及上沿附近且没有跌破区间另一侧 → 开多。
- 做空：六均线压缩区形成 → 收盘价向下突破区间下沿 → 突破后第一次反抽触及下沿附近且没有涨破区间另一侧 → 开空。
- 突破 K 线不能同时充当回踩 K 线；超时、第一次回踩失守或穿越区间另一侧都会取消机会。
- 止损位固定在原密集区另一侧；止盈按入场时风险距离计算固定 R 倍数。
- 未加入 ADX、成交量、4H 趋势或其他额外过滤器。`volume > 0` 仅用于排除无成交数据行，不是信号过滤条件。

### 最终研究参数

| 参数 | 数值 |
|---|---:|
| 周期 | 1H |
| compression | 0.015 |
| breakout | 0.005 |
| 第一次回踩最长等待 | 3 根 K 线 |
| pullback tolerance | 0.005 |
| 固定止盈 | 5R |
| 最大同时持仓 | 3 |
| 主研究风险 | 3x / 每笔 1% |

## 数据与实验隔离

- 市场：Binance USDT-M 永续合约。
- K 线：1H；同时导入主力合约 K 线、标记价格和实际资金费事件。
- 初始资金：100 USDT；逐仓；多空双向；动态复利仓位。
- 费用：回测包含开仓/平仓手续费、资金费和交易所精度约束。
- 训练：2021-01-01 至 2024-12-31。
- 验证：2025-01-01 至 2025-12-31。
- 最终留出：2026-01-01 至 2026-08-09 23:00 UTC。
- 参数搜索：80 轮，比较 compression、breakout、回踩容差、等待时间、3R/5R/8R/10R。
- 先按训练结果选前五名，再只用 2025 选出 epoch 61；之后冻结信号参数。3x/1% 根据 2021–2025 风险矩阵确定，最后才运行 2026 留出。

小币历史从实际合约上市日开始，不能人为补齐到 2021。例如 SUI 从 2023-05-03、WIF 从 2024-01-18、ENA 从 2024-04-02、RENDER 从 2024-07-26 开始。完整范围见 `data-availability.csv`。

由于本机访问 Binance 主站市场元数据接口返回地区限制，合约符号/精度元数据使用 Binance Futures Testnet 公共接口；所有价格、标记价格和资金费历史仍来自 Binance 主网官方公共归档，并逐个校验 SHA-256。此限制应在换地区或实盘前重新验证。

胜率低、单次赔率高符合原策略理念；问题不在盈亏比，而在 2026 年有效信号比例明显下降，导致 PF 跌破 1。

## 100U → 10,000U 判断

不成立。

1. 冻结主方案全期最高只有 752.92U，最终 325.94U。
2. 风险矩阵所有 9 组截至 2025 年底均未达到 10,000U。
3. 最高历史终值的 3x/2% 只有 2,015.68U，并承担 62.73%回撤。
4. 10x/5% 最大回撤 99.54%，已经接近资金归零。
5. 独立 2026 留出 PF 小于 1，说明当前 V1 不是稳定正期望系统。

## 下一轮建议

当前结果最适合保留为 V1 基线，不直接实盘。下一轮只增加一个变量并使用滚动前推验证：

1. 优先测试 README 原定 V2 的 4H 趋势方向过滤，不改变 1H 入场状态机。
2. 每轮固定训练/验证/留出窗口，不能根据 2026 亏损币事后删币。
3. 继续以 3x/1% 为基准；先提高 PF 和降低回撤，再讨论 2%风险。
4. 使用 dry-run/paper trading 收集至少 100–200 笔样本后，再决定是否半自动执行。
5. V2 若留出 PF 仍低于 1，应停止这条策略线，而不是继续堆叠 ADX、成交量等条件。
